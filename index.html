📚 Fundamental IUPAC Nomenclature Rules

1. Writing Order and Naming (Ionic Compounds)

The fundamental rule is to write the cation first and then the anion (e.g., NaCl), but to name them in reverse order: Anion Name + Cation Name.

Ex: NaCl → anion (Cl⁻, chloride) + cation (Na⁺, sodium) → Sodium chloride.

Ex: CaSO₄ → anion (SO₄²⁻, sulfate) + cation (Ca²⁺, calcium) → Calcium sulfate.

2. Cations with Multiple Oxidation States (Stock System)

For metals that can form cations with different charges (common in transition metals), the ion charge is indicated by a Roman numeral in parentheses, immediately after the metal name (no space).

Ion Name (Stock) Name (Old) Example Compound
Fe²⁺ Iron(II) Ferrous FeCl₂ → Iron(II) chloride
Fe³⁺ Iron(III) Ferric FeCl₃ → Iron(III) chloride
Cu⁺ Copper(I) Cuprous Cu₂O → Copper(I) oxide
Cu²⁺ Copper(II) Cupric CuO → Copper(II) oxide

💡 Tip

In the old nomenclature, the suffix -ous is used for the lower oxidation state and -ic for the higher oxidation state.

3. Multiplicative Prefixes (Molecular Compounds)

Used mainly for binary compounds formed between nonmetals (e.g., acidic oxides, nonmetal halides). The prefixes indicate the number of atoms of each element.

No. Prefix Example Name
1 mono- CO Carbon monoxide (mono- is omitted for the second element)
2 di- CO₂ Carbon dioxide
3 tri- SO₃ Sulfur trioxide
4 tetra- CCl₄ Carbon tetrachloride
5 penta- P₂O₅ Diphosphorus pentoxide
6 hexa- SF₆ Sulfur hexafluoride
7 hepta- Cl₂O₇ Dichlorine heptoxide
8 octa- Cl₂O₈ Dichlorine octoxide
9 nona- I₂O₉ Diiodine nonoxide
10 deca- P₄O₁₀ Tetraphosphorus decoxide

Systematic Nomenclature of Oxyanions

The nomenclature of most oxyanions follows a pattern relative to the number of oxygen atoms. A "standard" anion is defined for each element, which receives the suffix -ATE. All other names are derived from it.

Standard ...ate ClO₃⁻ BrO₃⁻ IO₃⁻ Chlorate
1 less than the standard ...ite ClO₂⁻ BrO₂⁻ IO₂⁻ Chlorite

🧪 Acid Nomenclature and Table

The name of an acid is directly derived from the name of the anion it forms when it ionizes in water. Converting names is the key to understanding the whole system.

Golden Rule: Anion → Acid Conversion

ANION Suffix ACID Suffix Example (Anion → Acid)
-IDE → -HYDRIC Chloride (Cl⁻) → Hydrochloric acid (HCl)
-ITE → -OUS Sulfite (SO₃²⁻) → Sulfurous acid (H₂SO₃)
-ATE → -IC Sulfate (SO₄²⁻) → Sulfuric acid (H₂SO₄)

💡 Mnemonic Tip

Remember: -ite → -ous, -ate → -ic, and -ide → hydro...-ic.
